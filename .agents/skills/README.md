# Add Codex skills here

Create one folder per skill:

```text
.agents/skills/
└── example-skill/
    ├── SKILL.md
    ├── scripts/       # optional
    ├── references/    # optional
    └── assets/        # optional
```

The `SKILL.md` frontmatter must include a unique `name` and a precise `description` explaining when the skill should trigger.
