# Client engagement template

These files are sanitized starting points. Copy them into a client-approved private workspace before filling them out. Do not place completed client documents in this public/shared source repository.

Suggested sequence:

1. `discovery-questionnaire.md`
2. `process-inventory.md`
3. `opportunity-scorecard.md`
4. `solution-design.md`
5. `acceptance-checklist.md`
6. `operations-runbook.md`
