# Solution design

## Outcome and scope

State the measurable outcome, included process steps, exclusions, users, and client owner.

## Flow

Document triggers, validated inputs, decisions, AI-assisted steps, deterministic rules, human approvals, external actions, outputs, and audit events.

## Failure handling

Define timeouts, retries, idempotency keys, rate limits, partial-failure behavior, alerting, manual recovery, rollback, and support ownership.

## Data and security

List systems, data classifications, model providers, retention, permissions, credential storage, redaction, and tenant-isolation controls.

## Measurement

Record the baseline, target, instrumentation, evaluation dataset, acceptance threshold, and review cadence.
